# 🌳 Kinship: Premium Family Tree Application

Kinship is a high-end, full-stack family tree visualization platform. It features a modern, glassmorphic UI and an interactive infinite canvas for mapping out family lineages with persistent positions and relationships.

## ✨ Core Features
- **Secure Authentication**: Full login, signup, password reset, and social OAuth (Google, GitHub) powered by Supabase.
- **Interactive Canvas**: Infinite zoomable/pannable workspace built with React Flow.
- **Symmetric Junctions**: Automated marriage junction nodes that center perfectly between spouses.
- **Auto-Alignment**: Sibling children are automatically aligned and spaced in a single row.
- **Relationship Persistence**: Drag-to-connect parents and children with "Comb" and "L" routing.
- **Export & Share**: Easily export your beautifully rendered family tree to PDF or image formats.
- **Position Memory**: Members and junctions stay exactly where you place them.

## 🚀 Tech Stack
- **Frontend**: React (Vite), React Flow (`@xyflow/react`), Framer Motion, Lucide Icons.
- **Backend as a Service (BaaS)**: Supabase (Database, Auth).
- **Exporting**: `html2canvas` & `jspdf`.
- **Styling**: Modern Glassmorphic Vanilla CSS.
